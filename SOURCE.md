# Source and scope

This is the standalone experimental program extracted on 26 October 2026
from the experimental implementation at
[`da5cab49d986edb2d185464a922d8d038f3ae6b0`](https://github.com/YaoZeLiu0417/uhf-fmri-qc-notes/tree/da5cab49d986edb2d185464a922d8d038f3ae6b0).
The historical measurement
repository's base revision was
[`b0a60bef27637a727681571996ab927aee61b4f9`](https://github.com/YaoZeLiu0417/uhf-fmri-qc-notes/tree/b0a60bef27637a727681571996ab927aee61b4f9).
That earlier revision is a measurement reference, not the commit containing
this program.

The extraction preserves the `experiments.interoception` Python module paths,
the eight experiment test modules, the protocol and interface documentation,
the shared program artwork, demonstration media and two synthetic software
verification records. Core algorithms and test modules remain unchanged.
The standalone UI uses the project name **Real-Time Interoception Work Platform**.
Its documentation media are regenerated from the shared renderer.
The root README and experiment setup notes are
adapted to the standalone layout. The site-profile template adds the reported
clinical equipment constraints and leaves all calibration evidence pending.

The previous physiology parsing/QC pipeline, participant or raw MRI/physiology
data, measurement-result files and unused early presentation diagrams are
excluded. The only retained result records describe synthetic software checks
and synthetic native-window smoke runs. Public author masks are linked in the
protocol and are not redistributed under this project's licence.

The original [MIT licence](LICENSE), including `Copyright (c) 2026 Yaoze Liu`,
is retained. Documentation artwork is generated by this project's renderer;
no reference-site media, GradCPT photographs or system fonts are bundled.
